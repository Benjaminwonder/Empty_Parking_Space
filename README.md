# Empty_Parking_Space
Building an program that keeps track of open parking spots on Stetson campus for software dev II class
A vehicle detector plus a one-time camera to lot-map transform assigns every car to a stall​
An on-site edge unit publishes stall states only, — no video leaves the lot​
Shortest-path routing over the lot’s lane graph, picks the closest open stall​
A short hold on the assigned stall keeps two drivers off the same space​
